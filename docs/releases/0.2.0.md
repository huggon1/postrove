# Postrove 0.2.0

Postrove 0.2.0 introduces a topic workspace, language experts with automatic translation, and Windows packages alongside macOS.

## Topic workspace

- Start a topic and choose its AI members. Each member replies independently; open the topic to read answers and collect individual, selected, or all sources into Reading.
- Inspect member receipts for reply, source, and processing states. Stop an individual member while the others continue. Captured answers remain available after a later processing failure.
- Configure daily or weekly scheduled messages. Each send creates a new topic while the application is running.
- Use redesigned member setup, Telegram and Feishu connections, model configuration, and forms, with a new blue app icon and responsive layouts.

## Language experts and translation

- Enable Chinese and English Grok experts through one X sign-in. YouTube/Gemini experts share one Google sign-in. Xiaohongshu/点点 uses Chinese; Reddit AI search uses English.
- Ask in your own language. Postrove translates the question for the selected expert, then prepares replies and collected material in your reading language. Original text and links remain available for comparison.
- Set interface and reading languages separately. Fresh profiles use Simplified Chinese when the primary system language is Chinese, and English otherwise. Saved language choices keep precedence.

YouTube/Gemini and Reddit AI members are experimental. Their availability and source coverage depend on the platform and account access. Gemini uses a Google account; Reddit AI supports guest questions and optional sign-in.

## Reading and reusable results

- Read public YouTube video details and available original captions, with timestamp links and creator-supplied material. The reader records the content it retrieved and retains partial results when access is limited.
- Read public Reddit posts or a selected comment with its parent post and relevant ancestor context. GitHub repository reading focuses on the default README; X and Xiaohongshu reading share the account connected in Members.
- Open Markdown result files for topics and reading jobs to continue working with another Agent. Each completed attempt retains its original captures and prepared reading version.

## Desktop packages

The Release provides a macOS Apple silicon DMG and a Windows x64 EXE. Windows installs per user and offers an installation-directory choice. Both platforms support application updates through Settings → About in 0.2.0.

Install Google Chrome for platform access. macOS packages use the project's signing certificate; first launch may require System Settings → Privacy & Security → Open Anyway. Windows installers are unsigned. Platform sign-in requirements appear in the [capability tables](../../README.md#features).

## Upgrading from 0.1.2

macOS users can update through Settings → Application updates in 0.1.2, or install the new DMG. Windows installation-trial users can install the 0.2.0 EXE.

The upgrade retains saved content, model connections, bot settings and accepted messages, browser sessions, cached images, and result files. Historical search results appear as topics; saved follows become scheduled messages. Original questions, answers, source associations, and dates retain their saved values. Existing interface and reading language preferences remain selected.
