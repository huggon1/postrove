# Postrove 0.2.3

Postrove 0.2.3 improves reading results, video transcription recovery, and account controls on macOS Apple silicon and Windows x64.

## Reading

- The reader's copy icon copies the absolute path of the current result's `result.md` file for use in a coding agent. Hovering over the icon shows its action label.
- Manually entered and forwarded browser addresses accept an omitted HTTPS prefix while retaining paths, query parameters, and source-access tokens.
- Bilibili reading retains the title, description, creator, cover, and selected video-part metadata alongside accessible captions or local speech transcription.
- Xiaohongshu video reading accepts accessible audio from its media CDN and preserves the written description, cover, and source references. Portrait covers fit their reading cards.
- Successful video captures survive a later Agent output failure. Source issues retain their own partial state and recovery path alongside translation and introduction results. A failed retry retains saved content.

## Accounts

- Connection settings show the saved account name and available platform identifier after a successful self-account observation.
- The home icon opens the platform homepage in the application's existing signed-in Chrome profile.
- Login completion captures the account name once. The refresh icon reads it again; ordinary settings views show the saved value. Refresh failure retains the same session's prior name and shows feedback. Account switches and sign-out clear the previous identity.
- Homepage, refresh, and result-path icons show their action labels on pointer hover and keyboard focus.

## Local speech

- macOS packaging records speech-runtime hashes after signing nested components. Runtime checks continue to detect changed component bytes.

## Upgrading from 0.2.2

Update through Settings → About, or install the [macOS DMG or Windows EXE](https://github.com/huggon1/postrove/releases/tag/v0.2.3). Reports, reading materials, model connections, settings, and platform sessions remain in the Postrove profile.

Source platforms determine sign-in, account-name availability, captions, and media access. Local transcription requires the separately installed speech model. Recognition quality depends on source audio and language; video-frame content retains its existing coverage limits.

The [installation guide](../../README.md#installation-and-use) describes supported systems and first-open approval. The [release guide](../releasing.md#signing-and-assets) describes signing and update packages.
