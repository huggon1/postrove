# Postrove 0.2.1

Postrove 0.2.1 brings the fixes and improvements merged since 0.2.0 to macOS Apple silicon and Windows x64.

## Questions and reading

- Search questions use a dedicated translation flow. When the detected language matches the expert language, Postrove submits the original question. Invalid translation output receives one correction attempt; a repeated failure stops submission for that language. This addresses [Issue #100](https://github.com/huggon1/postrove/issues/100).
- Members using the same language share one saved question preparation within a topic. Recovered topics reuse saved successful or failed language preparations.
- Replies receive translation and Markdown formatting in one reading-version operation. Mixed-language content retains passages already in the reading language. Original replies remain available for comparison.
- Material translation keeps Markdown blocks together, preserves links and code, and resumes saved unfinished chunks after a failure.
- Gemini captures its complete reply and returns validated original YouTube video links. YouTube reading keeps caption timestamps and source identity, with browser capture available when the caption tool fails or is absent.

## Settings and logs

- Background model settings separate connection activation, current model selection, configuration editing, and connection checks. Checks follow the saved model and options; changing the execution configuration cancels an outstanding check. Running tasks retain their selected configuration.
- Task logs export as one named HTML file with an index and native session navigation. The export includes retained attempts and opens offline.
- Settings menus and expandable controls use consistent interaction indicators. Members shows an account-risk reminder before platform sign-in.

## Scheduled messages and product guides

- Scheduled messages support one-time, daily, selected-weekday, monthly, and fixed minute or hour intervals. Configure multiple times, a time zone, and date bounds, then preview upcoming sends. Each occurrence creates a topic while Postrove is running.
- The bilingual website, product walkthroughs, and architecture diagrams reflect the current search and reading flows.

## Upgrading from 0.2.0

Update through Settings → About, or install the new [macOS DMG or Windows EXE](https://github.com/huggon1/postrove/releases/tag/v0.2.1). Reports, reading materials, model connections, settings, and platform sessions in the Postrove profile stay saved.

Installed builds use `Postrove/profiles/default` inside the operating system's application-data directory. Profiles stored under an earlier product name require a separate, backed-up migration before this update.

Platform access uses Google Chrome. Gemini and Reddit AI members remain experimental; results and access depend on the platform and account. Installation and signing details appear in the [installation guide](../../README.md#installation-and-use).
