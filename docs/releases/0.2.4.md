# Postrove 0.2.4

Postrove 0.2.4 improves navigation, drafts, and recovery controls on macOS Apple silicon and Windows x64. The website also provides complete English and Simplified Chinese pages.

## Reading and topics

- The reader keeps material, version, Stop, and Retry controls above scrolling content. The current window session retains the search query and each material/version's reading position as images finish sizing.
- Topic replies include member navigation. Repeated source links share one selection, and collection errors appear beside the action that failed. Source titles open their original page; Reading opens the collected material.
- Partial, failed, and stopped topics offer Ask again. It fills the composer with the saved question and currently enabled recipients. Replacing a different draft asks you to choose Keep draft or Replace draft.
- Topic icons reflect their recorded outcome. Reading phase labels follow the interface language.

## Forms and operation feedback

- Composer, schedule, model, and bot setup drafts survive navigation and temporary dismissal in the current window session. Explicit Cancel discards schedule and model-editor drafts; a successful submission consumes its submitted draft.
- Pending actions and errors stay beside their controls. Failed account, speech, and workspace reads offer Reload. Confirmation dialogs show their own operation errors.
- Menus support outside-click and keyboard dismissal, restore focus after Escape, and fit the available space. Dialogs retain pending submissions and focus their initial control.
- Model options support Enter to save and focus fields that need correction. Reauthorization updates the edited connection while preserving its active or inactive status.
- Link intake and authentication submissions retain their input while awaiting a response. Failed authentication retains the entered answer for correction or retry.

## Layout and schedules

- Navigation fits compact desktop widths, including the application's 640-pixel minimum. Reading metadata and action targets use the shared sizing rules.
- Home and schedule cards show upcoming sends in the schedule's saved time zone. A schedule whose name matches its question presents that question once.
- Disabling an expert shows how many saved schedules are affected and how many will pause.

## Website

- English and Simplified Chinese URLs return complete pages before browser scripts run. Language links open the corresponding page, and existing language-query links route to it.
- Each page includes its own title, description, language links, and product metadata. The website also supplies a sitemap and setup, platform, and local-data answers from the READMEs.

## Upgrading from 0.2.3

Update through Settings → About, or install the [macOS DMG or Windows EXE](https://github.com/huggon1/postrove/releases/tag/v0.2.4). Reports, reading materials, model connections, settings, and platform sessions remain in the Postrove profile. Drafts and reading positions described above belong to the current window session.

The [installation guide](../../README.md#installation-and-use) describes supported systems and first-open approval. The [release guide](../releasing.md#signing-and-assets) describes signing and update packages.
