# Postrove 0.2.5

Postrove 0.2.5 helps you spot connection problems before sending a topic, refresh a model catalog from Settings, and open saved reading results with a coding agent.

## Topic connections

- Postrove checks the active OAuth model connection on startup, when you return to the app, and when you switch models. If authorization is rejected, the composer offers a direct link to the connection's authentication step and keeps your question.
- When an account needs sign-in, the composer marks affected recipients. You can sign in directly or send to the available members. Reddit supports guest questions.
- A shared model authentication failure appears once in the topic. A platform login, verification, or account confirmation opens the relevant platform from the affected member's reply or receipt.

## Model catalogs and reading

- Refresh catalog updates a signed-in built-in provider's model list in the connection editor and keeps your draft settings. Select and save a different model to apply it.
- The [Postrove Reading skill](../../skills/postrove-reading/) lets a coding agent locate and open saved reading results when you explicitly invoke it. The [README](../../README.md#collect-content-to-read-later) shows how to install it.

## Upgrading from 0.2.4

Update through Settings → About, or install the [macOS Apple silicon DMG or Windows x64 EXE](https://github.com/huggon1/postrove/releases/tag/v0.2.5). Reports, reading materials, settings, model connections, and platform sessions stay in your Postrove profile.

The [installation guide](../../README.md#installation-and-use) explains first launch. The [release guide](../releasing.md#signing-and-assets) describes signing and update packages.
