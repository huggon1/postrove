# Application screenshots

The root READMEs use three scenes in English and Simplified Chinese:

- `topics-*.png`: topic workspace, member selection, and scheduled messages.
- `topic-*.png`: an independent member reply with collectible sources.
- `reading-*.png`: a saved article with a reading version and an original-text switch.

The images capture the running application with separate local profiles. Questions, replies, source identities, and reading material are fictional examples. The reading illustration was created for these examples. Each image is a 2200 × 1520 PNG.

Refresh both language sets when the corresponding interface changes. Keep the sample-data caption beside the first screenshot in each root README.
